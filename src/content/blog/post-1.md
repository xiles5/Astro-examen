# ¿Qué es Astro?

Astro es un framework moderno para crear sitios web rápidos, optimizados y fáciles de mantener. Está especialmente pensado para páginas de contenido, blogs, portfolios, páginas corporativas y sitios que necesitan un buen rendimiento.

Astro permite utilizar HTML, CSS y JavaScript, además de integrarse con tecnologías y frameworks como React, Vue, Svelte y otros.

Una de sus principales características es que intenta enviar al navegador la menor cantidad de JavaScript posible, lo que ayuda a que las páginas carguen rápidamente.

¿Para qué sirve Astro?

Astro sirve para desarrollar sitios web modernos utilizando componentes reutilizables y diferentes tecnologías web.

Con Astro podemos crear:

Blogs.
Portfolios.
Páginas empresariales.
Tiendas online.
Documentación.
Landing pages.
Sitios web estáticos y dinámicos.

También permite trabajar con contenido escrito en Markdown y organizar proyectos utilizando componentes y layouts reutilizables.

¿Por qué utilizar Astro?

Una de las principales ventajas de Astro es su enfoque en el rendimiento. Por defecto, gran parte del contenido puede generarse como HTML y enviarse directamente al navegador sin necesidad de ejecutar JavaScript para mostrarlo.

Esto puede ayudar a mejorar la velocidad de carga y la experiencia del usuario.

Además, Astro permite utilizar diferentes herramientas dentro de un mismo proyecto, por lo que los desarrolladores pueden combinar tecnologías según las necesidades de cada página.
