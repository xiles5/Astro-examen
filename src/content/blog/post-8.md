# ¿Qué es el DOM?

El DOM (Document Object Model) es una representación de la estructura de un documento HTML que permite a JavaScript acceder y modificar los elementos de una página.

Gracias al DOM, JavaScript puede cambiar textos, estilos, atributos y elementos HTML.

¿Para qué sirve?

El DOM permite crear páginas dinámicas e interactivas.

Por ejemplo, podemos hacer que un botón cambie un texto, abra un menú o modifique una imagen sin tener que recargar toda la página.

El DOM es fundamental para desarrollar interfaces web interactivas utilizando JavaScript.
