# ¿Qué es JavaScript?


JavaScript es un lenguaje de programación utilizado para añadir interactividad y lógica a las páginas web.

A diferencia de HTML y CSS, JavaScript permite ejecutar instrucciones, realizar cálculos, modificar elementos de una página y responder a las acciones del usuario.

¿Para qué sirve JavaScript?

JavaScript permite crear funcionalidades como menús interactivos, formularios dinámicos, galerías de imágenes, juegos, validaciones y aplicaciones web completas.

También puede utilizarse en el servidor mediante tecnologías como Node.js.

JavaScript es una de las tecnologías principales del desarrollo web moderno.
