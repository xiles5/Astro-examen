# Git y GitHub

Git es un sistema de control de versiones que permite registrar los cambios realizados en un proyecto.

Gracias a Git podemos volver a versiones anteriores, crear ramas y trabajar con diferentes cambios sin perder el código.

¿Qué es GitHub?

GitHub es una plataforma que permite almacenar repositorios Git en Internet y colaborar con otros desarrolladores.

¿Para qué sirven?

Git y GitHub son herramientas muy utilizadas en el desarrollo profesional.

Permiten guardar proyectos, controlar versiones, colaborar con equipos y publicar código.

Git permite mantener un historial del proyecto y GitHub facilita almacenar y compartir ese proyecto online.
