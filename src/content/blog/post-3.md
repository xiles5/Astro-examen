# ¿Qué es HTML?

HTML: los fundamentos que todo desarrollador web debe conocer
¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje utilizado para crear y estructurar el contenido de una página web. Permite definir elementos como títulos, párrafos, imágenes, enlaces, listas, tablas y formularios.

HTML utiliza etiquetas para indicar al navegador qué representa cada elemento de la página.

¿Para qué sirve HTML?

HTML sirve para construir la estructura básica de un sitio web. Por ejemplo, podemos utilizarlo para crear el encabezado, el contenido principal, las secciones y el pie de página.

HTML es uno de los conocimientos fundamentales del desarrollo web y normalmente se combina con CSS y JavaScript.

HTML define qué contenido existe en una página, mientras que CSS se encarga principalmente de su apariencia y JavaScript de su comportamiento.
