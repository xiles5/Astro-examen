# ¿Qué es CSS?

CSS (Cascading Style Sheets) es un lenguaje utilizado para controlar la apariencia y el diseño de las páginas web.

Con CSS podemos modificar colores, tamaños, fuentes, márgenes, espacios, posiciones, animaciones y muchos otros aspectos visuales.

¿Para qué sirve CSS?

CSS sirve para transformar una estructura HTML sencilla en una interfaz atractiva y organizada.

También permite crear páginas responsive, es decir, páginas capaces de adaptarse a diferentes tamaños de pantalla como ordenadores, tablets y teléfonos móviles.

HTML proporciona la estructura y CSS proporciona principalmente el diseño visual.
