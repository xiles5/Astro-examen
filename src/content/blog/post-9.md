# ¿Qué es una API?

Una API (Application Programming Interface) permite que diferentes aplicaciones puedan comunicarse entre sí.

En desarrollo web, las APIs se utilizan frecuentemente para enviar y recibir información entre un frontend y un servidor.

¿Qué es una API REST?

REST es un estilo de arquitectura utilizado para diseñar servicios web que normalmente trabajan mediante HTTP.

Una API REST puede utilizar métodos como:

GET para obtener información.
POST para crear información.
PUT o PATCH para modificar información.
DELETE para eliminar información.
¿Para qué sirve?

Las APIs permiten conectar una página web con servicios externos o con un backend.

Por ejemplo, una aplicación meteorológica puede utilizar una API para obtener información sobre el clima.

Las APIs son fundamentales para crear aplicaciones web modernas que necesitan trabajar con datos.
